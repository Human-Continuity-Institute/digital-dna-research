# Digital DNA Research

**Human Continuity Institute** -- human-continuity.org

This repository is the open collaboration space for the Digital DNA project: turning many years of a person's photos and artifacts into a measurable, structured "digital essence."

Read the full contributor brief: [`docs/CONTRIBUTOR-BRIEF.md`](docs/CONTRIBUTOR-BRIEF.md)

## Get involved

- Start here: open the [Discussions](../../discussions) tab and introduce yourself in the kickoff thread
- - Read the brief above for objectives, what's already feasible today, and the open questions we need help answering
  - - No commitment required to just weigh in -- feasibility opinions from working ML/CV engineers are exactly what this phase needs
   
    - ## Status
   
    - Early planning phase. No code yet -- we are aligning on scope, tooling, and a first two-week proof-of-concept plan before writing anything.
   
    - ## A note on data
   
    - All open collaborative development happens against small, synthetic, or public sample datasets -- never real personal photos. Any work involving real personal archives happens in a private, access-controlled environment under a separate agreement.
